# Style and conventions

- Vanilla semantic HTML, CSS custom properties, and native ES modules. No framework or CSS preprocessor.
- CSS is split by responsibility: tokens.css, base.css, layout.css, components.css, responsive.css. Reuse semantic custom properties; avoid raw hardcoded component values.
- Responsive CSS uses logical properties and existing rem breakpoints.
- JavaScript modules use named exported initializer/functions, data-* hooks, native controls, and accessible state attributes such as aria-expanded. Preserve focus handling, Escape handling, inert backgrounds, and reduced-motion behavior.
- Tests use Node test and Playwright with descriptive behavior names. Visual baselines live beside visual.spec.mjs.
- PHP classes are PSR-4 under JackLanding\\, target PHP >=8.1, and keep secrets outside public/.
- Root GitHub Pages files are generated by npm run build:pages; edit public sources first.
- Never stage debug.log, server/config.php, storage JSON, test-results, or generated temporary directories.
