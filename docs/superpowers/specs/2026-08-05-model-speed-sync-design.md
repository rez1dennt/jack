# Синхронизация скорости JACK J6 и JACK M9

## Цель

Исключить расхождение между выбранной моделью, таблицей характеристик, изображением оборудования и подписью скорости в карточке преимуществ.

## Поведение

- При первоначальной загрузке выбрана JACK J6, а карточка скорости показывает «До 3 000 ст/мин (JACK J6)».
- После выбора JACK M9 карточка показывает «До 3 600 ст/мин (JACK M9)».
- При возврате на JACK J6 восстанавливается значение 3 000 ст/мин.
- Одинаковое обновление выполняется при клике и при клавиатурном переключении вкладок.

## Реализация

- Каждая кнопка модели хранит собственную подпись скорости в `data-speed-copy` рядом с уже существующими данными изображения.
- Абзац скорости получает стабильный хук `data-model-speed` и начальный текст JACK J6, чтобы информация оставалась корректной до загрузки JavaScript.
- Существующая функция выбора вкладки обновляет изображение и подпись скорости из данных активной кнопки. Дублировать карточки преимуществ для каждой модели не нужно.

## Проверка

- E2E-тест подтверждает начальные 3 000 ст/мин для J6.
- После клика по M9 тест подтверждает 3 600 ст/мин.
- После клавиатурного возврата на J6 тест подтверждает 3 000 ст/мин.
- Существующие проверки таблиц, изображений и доступности вкладок продолжают проходить.
