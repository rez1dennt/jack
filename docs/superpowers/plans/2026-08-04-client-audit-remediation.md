**Goal:** Replace placeholder and unsupported landing-page content with the client's real video, verified company information, and exact JACK J6/JACK M9 specifications while preserving the existing visual system, responsive behavior, and form implementation.

**Architecture:** Keep `public/` as the canonical PHP-hosting source and the repository root as generated GitHub Pages output. Treat client media and the combined technical PDF as static assets copied by the existing Pages builder.

**Tech Stack:** Semantic HTML5, vanilla CSS custom properties, native ES modules, Playwright, Node test, Python/reportlab for the checked-in PDF artifact, ImageMagick for the checked-in WebP asset, GitHub Pages static build.

- Preserve the existing 1440 px container system, fixed header, red/dark visual language, focus styles, menu scroll lock, cookie banner, and lead-form behavior.
- Canonical source changes happen under `public/`; root Pages files are generated by `npm run build:pages`.

- The technical section must present JACK J6 and JACK M9 configuration M9-SS-F13-X values exactly as specified in the approved design.

- New behavior follows test-first RED/GREEN cycles.
- Interactive model selectors and the video dialog must meet WCAG 2.2 AA keyboard, name/role/state, focus, and reflow requirements.
- Decorative images keep empty alt text; meaningful images receive concise Russian alternatives.

Create `public/assets/js/spec-tabs.js`:

```js
export function initSpecTabs(root) {
  if (!root) return () => {};

  const tabs = [...root.querySelectorAll('[role="tab"]')];
  const panels = [...root.querySelectorAll('[role="tabpanel"]')];
  if (tabs.length === 0 || panels.length === 0) return () => {};

  const activate = (nextTab, { moveFocus = false } = {}) => {
    for (const tab of tabs) {
      const selected = tab === nextTab;
      tab.setAttribute('aria-selected', String(selected));
      tab.tabIndex = selected ? 0 : -1;
    }
    for (const panel of panels) panel.hidden = panel.id !== nextTab.getAttribute('aria-controls');
    if (moveFocus) nextTab.focus();
  };

  const handleClick = (event) => activate(event.currentTarget);
  const handleKeydown = (event) => {
    const currentIndex = tabs.indexOf(event.currentTarget);
    let nextIndex = currentIndex;
    if (event.key === 'ArrowRight') nextIndex = (currentIndex + 1) % tabs.length;
    else if (event.key === 'ArrowLeft') nextIndex = (currentIndex - 1 + tabs.length) % tabs.length;
    else if (event.key === 'Home') nextIndex = 0;
    else if (event.key === 'End') nextIndex = tabs.length - 1;
    else return;
    event.preventDefault();
    activate(tabs[nextIndex], { moveFocus: true });
  };

  for (const tab of tabs) {
    tab.addEventListener('click', handleClick);
    tab.addEventListener('keydown', handleKeydown);
  }
  activate(tabs.find((tab) => tab.getAttribute('aria-selected') === 'true') || tabs[0]);

  return () => {
    for (const tab of tabs) {
      tab.removeEventListener('click', handleClick);
      tab.removeEventListener('keydown', handleKeydown);
    }
  };
}
```

