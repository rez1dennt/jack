# Лендинг промышленного оборудования Jack

Статический адаптивный frontend на HTML, CSS и JavaScript с защищённым PHP-обработчиком заявок через PHPMailer.

## Локальный запуск

Требования: Node.js 22+, PHP 8.1+ с расширениями OpenSSL и mbstring, Composer 2.

```powershell
npm install
npx playwright install chromium
php -c tools/php.ini tools/composer.phar install
npm run test:e2e
```

Для простого просмотра без тестов:

```powershell
php -c tools/php.ini -S 127.0.0.1:8080 -t public
```

## Размещение на хостинге

1. Указать `public/` как корень сайта. Если панель хостинга использует `public_html`, перенести содержимое `public/` в `public_html`, а каталог `server/` разместить рядом с ним.
2. Выполнить `composer install --no-dev --optimize-autoloader` в корне проекта или загрузить подготовленный каталог `vendor/`.
3. Скопировать `server/config.example.php` в `server/config.php` и заполнить его вне Git.
4. Включить HTTPS и расширения PHP `openssl`, `mbstring`, `json`.
5. Разрешить PHP запись только в `server/storage/`.
6. Перед запуском заменить все маркеры вида `[[...]]`, подключить реальный PDF и проверить юридические документы.

## Google SMTP

Используется пароль приложения Google, а не основной пароль аккаунта. Значения SMTP хранятся только в `server/config.php`. После публикации выполняется одна контролируемая тестовая заявка на согласованный адрес.

Google SMTP может приводить к трансграничной передаче персональных данных. Перед запуском оператору необходимо проверить применимость требований локализации, уведомления Роскомнадзора и трансграничной передачи для своей деятельности.
